Updated again — now using Cloudflare R2 storage buckets, bound to the kuqilin.eu.org domain. You can now gorge yourself on enjoy it at a reasonable pace. It’s way faster than jsDelivr! Within 20 seconds, 99% of users can load it. Go admire “Spring’s Depths” already 😠😠😠

After all kinds of battling wits (not really), I’ve finally got the website mascot working — a silent 37.
Why “battling wits”? Check below. It wasn’t easy. Turns out those little white patches were likely caused by a minor issue during the unpacking process by the original creator, leaving a white patch in the model texture. Looking at the texture image, it already seemed odd. I checked the skin in-game and saw there was nothing there originally, so I used IsoPix Pro to erase the white patch — finally, no more white blocks! (Should be fine, hopefully.)
I also adjusted the model’s position and size a bit. Unfortunately, I haven’t yet figured out how to add things like sign-holding or dialog boxes, so the mascot is a bit dopey.
Oh, and connecting directly to GitHub from mainland China is still a pain — even uploading the moc3 file to jsDelivr didn’t speed things up much. In the worst case, it could take you 2 whole minutes to see the beautiful 37! (Best case: 3 seconds.)

37 Spring’s Depths

Hahahaha, the content below is no longer timely — I got “Spring’s Depths” working!
The original title below was “Website Mascot — 37 Perfect Fluid”

After much effort, I finally vibe-coded a website mascot — the skin “Perfect Fluid” for the character 37 from Reverse: 1999.
Perhaps people who’ve played 1999 might ask: “Don’t you think ‘Joyful Birdcatcher’ or ‘Spring’s Depths’ looks better?” I’d answer: “Yes! I want to use Spring’s Depths too.”
It’s just that these have a “teensy” problem: For details, see the images below: See those white patches? 37’s E2 skin has the same issue. Vibe-coding couldn’t fix it I’m useless. No way around it. Spring’s Depths really is gorgeous — when deployed, little birds would even fly around — but I just couldn’t fix those white patches. Otherwise I wouldn’t have gone with this Luo Tianyi Perfect Fluid skin.

The Reimu theme I’m using natively supports Live2d, but unfortunately, your Reverse: 1999 model versions are too high, so I had to vibe-code it myself. Impressive, isn’t it, Deepseek-V4-Pro Preview?

Still, this skin isn’t bad-looking, and the animations and expressions are still there. I set up a 5-second auto-switch animation and a click-to-switch animation. Note: when the display width is less than 960px, the mascot won’t show — just like the sidebar; they’re synced.
Uh-oh, to speed up access from China, I uploaded this “potentially infringing” file to an image hosting service. Wonder what risks that might bring?

Still feels like such a pity I couldn’t make Spring’s Depths the website mascot 😭😭😭

These models were downloaded from https://github.com/myssal/Reverse-1999-CN-Asset/ — unpacked assets from a contributor. If there’s any copyright issue, please contact me for removal.
