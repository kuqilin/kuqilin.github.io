Headings

There are six levels of headings:

  • Level 1 heading # Level 1:

Level 1

  • Level 2 heading ## Level 2:

Level 2

  • Level 3 heading ### Level 3:

Level 3

  • Level 4 heading #### Level 4:

Level 4

  • Level 5 heading ##### Level 5:
Level 5
  • Level 6 heading ###### Level 6:
Level 6

The higher the level number, the smaller the heading, consistent with <h1>Level 1</h1>, <h4>Level 4</h4>, etc. in HTML.

Markdown HTML Rendered
# Level 1 heading <h1>Level 1 heading</h1>

Level 1 heading
… … …
###### Level 6 heading <h6>Level 6 heading</h6>
Level 6 heading

strikethrough <del>strikethrough</del> strikethrough

Lists

List syntax is divided into three types: unordered lists, ordered lists, and task lists.

Unordered Lists

Unordered lists begin with -, *, or +, followed by a space and then the content, e.g.:

  • Unordered list
    • Unordered list
      • Unordered list
- Unordered list
- * Unordered list
- * + Unordered list

Ordered Lists

Ordered lists consist of a number followed by a period, a space, and then the content, e.g.:

  1. Ordered list 1
  2. Ordered list 2
  3. Ordered list 3
1. Ordered list 1
2. Ordered list 2
3. Ordered list 3

The numbers don’t need to be in sequence, e.g. 1. 5. 6. 9., but they must be in ascending order.

Task Lists

Task lists consist of - followed by a space and a pair of square brackets [], with a space inside, e.g.:

- [ ] Task 1
- [ ] Task 2
  • Task 1
  • Task 2

If a task is completed, you can put an X inside the brackets, like this:

- [ ] Incomplete task
- [X] Completed task
  • Incomplete task
  • Completed task

Code

Markdown allows you to use a pair of triple backticks ``` to form a code block, for example:

Rendered:

This is a code block
 You can have line breaks inside

You can even add a language name on the top line to get syntax highlighting, for example:

Rendered:

print('markdown')

Or:

Rendered:

<?php echo "Markdown!";?>

If you want to insert an inline code snippet rather than a code block, you can wrap it in a pair of backticks `, e.g.:

Here is an inline code snippet `print`

Rendered:

Here is an inline code snippet print

Tables

In Markdown, use the pipe character | and dashes - to create tables. For example:

|Header 1|Header 2|Header 3|
|:--:|:--:|:--:|
|Content 1|Content 2|Content 3|

Rendered:

Header 1 Header 2 Header 3
Content 1 Content 2 Content 3

The colons : in |:--:| control alignment — : on the left means left-aligned, on the right means right-aligned, and on both sides means centered.

Footnotes

Footnotes are typically used in papers or when citing or referencing others’ work, for example:

Fierce-browed, I coolly defy a thousand pointing fingers; head-bowed, like a willing ox I serve the children.[^1]
[^1]:Quoted from Lu Xun's "Self-Mockery"

Rendered:

Fierce-browed, I coolly defy a thousand pointing fingers; head-bowed, like a willing ox I serve the children.1

Abbreviations

Abbreviations are similar to footnotes, but you don’t need to append [^1] or the like after the text, for example:

Markdown can be rendered as HTML by browsers.
*[HTML]:HyperText Markup Language

Rendered:

Markdown can be rendered as HTML by browsers.

*[HTML]:HyperText Markup Language

Formulas

Formulas are used for writing mathematical content and should be wrapped with $, for example:

The solution to the quadratic equation $ ax^2 + bx + c = 0 (b^2 - 4ac \ge 0) $ is:
$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $

The solution to the quadratic equation $ ax^2 + bx + c = 0 (b^2 - 4ac \ge 0) $ is:

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$
