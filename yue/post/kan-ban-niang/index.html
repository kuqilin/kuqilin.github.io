再次更新，用上了 Cloudflare 的 R2 储存桶，绑了kuqilin.eu.org域名，可以 尽情 适度食用了。速度比 jsDelivr 快多了！20 秒之内 99% 的用户都能加载出来了。都去给我欣赏「泉眼深处」😠😠😠

太好了，经历各种斗智斗勇（bushi）终于把网站看板娘搞好了 —— 一个不会说话的 37。
为什么说斗智斗勇呢？你去看后文。不容易啊，最终发现有这些小白块大抵是因为大佬解包过程中出了一些小问题，导致模型图片里面有一个白块，当时看模型图片就感觉奇怪，上 9 看了皮肤，发现本来这里什么都没有，于是用 IsoPix Pro 把白块擦掉了，发现终于没有白块了（应该不会有什么问题的）。
然后也把模型放置位置和大小做了一些调整。可惜的是暂时还不会怎么给她添加例如举牌子、对话框之类的，所以看板娘傻傻的。
欸，国内裸连 GitHub 还是不太好，把 moc3 文件上传到 jsDelivr 上也没多快，你们最坏情况要 2 分钟才能看到美丽的 37！（最好情况是 3 秒）

37 完美的流体

Caution

哈哈哈哈哈，下面的内容没有时效性了，我搞定了泉眼深处
下文原标题为《网站看板娘 —— 37 完美的流体》

耗费许久，最终 vibe code 了网站的看板娘出来，《重返未来：1999》里面角色 37 的皮肤——完美的流体。
或许玩过 1999 的人会问：“难道你不觉得快乐的捕鸟人或者泉眼深处更好看吗？”我会回答：“对！我也想用泉眼深处。”
只不过，这几个有“亿点点”问题： 具体的情况，请看以下图片： 看到那几个白块了吗？37 的洞二皮也有这个问题，vibe 解决不了 我是废物 没办法了，泉眼深处真的很好看啊，部署出来还会有小鸟在飞来飞去，可是这个白块真的没办法解决，不然也不会用这个 洛天依 完美的流体了。

本来我用的 Reimu 主题是直接能用 Live2d 的，但是没办法，你 9 的模型版本太高了，只得自己 vibe 出来 厉不厉害你 Deepseek-V4-Pro 预览版？

不过还好，这个皮肤也不算难看。并且动作和表情也还是有的。调了一个 5 秒钟自动切换动画和一个点击切换动画。需要注意的是，在显示宽度小于 960px 的情况下这个看板娘是不会显示的，就跟侧边栏一样，她俩是同步的。
坏了，为了加快国内的访问速度，把这个“可能侵权”的文件上传到了图床，不知道会有什么风险呢？

还是感觉很可惜，没能让泉眼深处当网站看板娘😭😭😭
