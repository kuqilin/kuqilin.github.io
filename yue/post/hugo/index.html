記錄咗我喺 GitHub Pages 搭建 Hugo 嘅經歷

Tip

請務必睇晒全文先至開始操作，避免一啲不必要嘅錯誤。

安裝 Hugo

Windows

去官網下載 Hugo 嘅 exe 檔案，隨便搵個位擺，然後將佢加入環境變數就得。

Linux

先安裝 Hugo 嘅二進制檔案，可以喺官網度下載，亦可以直接用軟件套件管理器。考慮到 apt 更新極之緩慢，建議 Debian 系嘅去官網下載 deb 套件嚟安裝。

sudo apt install hugo    # Debian 系
yay -S hugo              # Arch 系

安裝完成之後，執行 hugo version 會見到類似以下嘅提示：

❯ hugo version  
hugo v0.164.0-ce2470e7012b5ab5fc4e10ebe4027e9f8d9e00dc+extended linux/amd64 BuildDate=2026-07-06T16:39:30Z VendorInfo=gohugoio

即係安裝完成。

創建項目

我哋用 hugo new site <項目名稱> 嚟創建項目，譬如：

❯ hugo new site myBlog  
Congratulations! Your new Hugo site was created in /home/kuqilin/myBlog.  
  
Just a few more steps...  
  
1. Change the current directory to /home/kuqilin/myBlog.  
2. Create or install a theme:  
  - Create a new theme with the command "hugo new theme <THEMENAME>"  
  - Install a theme from https://themes.gohugo.io/  
3. Edit hugo.toml, setting the "theme" property to the theme name.  
4. Create new content with the command "hugo new content <SECTIONNAME>/<FILENAME>.<FORMAT>".  
5. Start the embedded web server with the command "hugo server --buildDrafts".  
  
See documentation at https://gohugo.io/.

會見到成功嘅提示，跟住 cd 到項目文件夾 myBlog，按照提示進行配置。

創建或安裝主題

顯然，我哋係可以自己創建主題嘅，但係為咗白嫖方便，直接去 Hugo Themes 度下載一個啱心水嘅就得，呢度揀咗 hugo-theme-reimu 呢個主題。

主題安裝有幾種方式，推薦用 Git Submodule：

cd myBlog
git init
git submodule add https://github.com/D-Sketon/hugo-theme-reimu.git themes/hugo-theme-reimu

亦可以直接下載主題壓縮包，解壓到 themes 文件夾度。

然後喺 hugo.toml 度指定主題：

theme = "hugo-theme-reimu"

配置 hugo-theme-reimu

主題嘅配置文件預設喺 themes/hugo-theme-reimu/config/_default/ 度。我哋唔應該直接修改主題文件，因為更新主題嗰陣會將佢覆蓋咗，所以應該喺項目根目錄嘅 config/_default/ 度創建同名文件嚟覆蓋。我哋將 params.yml（主題參數）複製過嚟就得。

基礎站點配置（hugo.toml） 

baseURL = 'https://<你嘅用戶名>.github.io/'
theme = "hugo-theme-reimu"
title = "xxx's Blog"       # 站點標題
locale = "zh-CN"           # 語言
languageName = "简体中文"   # 語言名稱
hasCJKLanguage = true      # 係咪包含 CJK 字符

[markup.highlight]         # 語法高亮（包含代碼塊必須）
guessSyntax = true
noClasses = false

[markup.goldmark.renderer]
unsafe = true

[markup.goldmark.extensions.passthrough] # 包含數學公式必須
enable = true
delimiters.block = [["\\[", "\\]"], ["$$", "$$"]]
delimiters.inline = [["\\(", "\\)"], ["$", "$"]]

unsafe = true 允許喺 Markdown 度直接用 HTML，passthrough 係用嚟支援數學公式嘅 $...$ 同 $$...$$ 語法。

主題參數配置（params.yml）

喺 config/_default/params.yml 度配置主題嘅各項功能，呢度介紹幾個關鍵項：

導航菜單：

menu:
  - name: home
    url: ""
  - name: archives
    url: "archives"
  - name: about
    url: "about"
  - name: friend
    url: "friend"

個人信息同頭像：

author: <你個名>
email: <你嘅郵箱>
avatar: "avatar.jpg"           # 擺喺 static/avatar/ 度
banner: "images/banner.webp"   # 擺喺 static/images/ 度

社交鏈接：

social:
  email: mailto:<你嘅郵箱>
  github: https://github.com/<你嘅用戶名>
  twitter: https://twitter.com/<你嘅用戶名>

側邊欄同小組件：

sidebar:
  position: left  # 左右可選
widgets:
  - category
  - tag
  - tagcloud
  - recent_posts

評論區（以 Waline 為例）：

comment:
  default: waline
waline:
  enable: true
  serverURL: "<你嘅 Waline 服務地址>"

啟用功能：

toc: true                # 目錄
dark_mode:
  enable: auto           # 自動跟隨系統
math:
  mathjax:
    enable: true         # 數學公式
show_update_time: true   # 顯示更新時間

更多配置項（鼠標特效、Live2D、字體、加載動畫等）請參考主題官方文檔。

配置完成之後，執行 hugo server -D 就可以喺本地預覽 http://localhost:1313。

其他內容

其他內容，譬如更改鼠標指標、修改字體、文章頭圖、文章封面、網站主題色、短代碼、友鏈等等，請睇官方文檔，呢度唔再贅述。嘻嘻

部署到 GitHub Pages

部署嘅核心思路係將 Hugo 構建生成嘅 public/ 目錄推送到 <用戶名>.github.io 倉庫。GitHub Pages 會自動將呢個倉庫嘅內容作為靜態網站發布。

即係話，我哋需要兩個倉庫：

  • 源碼倉庫（如 hugo-build）：擺 Hugo 項目源文件（Markdown、配置、主題等）
  • 頁面倉庫（<用戶名>.github.io）：淨係擺 public/ 入面嘅靜態文件

下面分別介紹手動推送同 GitHub Actions 自動推送兩種方式。

方式一：手動推送到 github.io

最直接嘅方式——喺本地執行 hugo 構建，然後將 public/ 目錄嘅內容推到頁面倉庫。

1. 複製頁面倉庫 

git clone https://github.com/<你嘅用戶名>/<你嘅用戶名>.github.io.git public

如果 public/ 目錄已經存在（Hugo 構建會生成），剷咗佢先再複製。

2. 構建並推送 

# 返去源碼倉庫根目錄，先構建
hugo

# 進入 public 目錄（呢個時候佢已經係頁面倉庫嘅複製）
cd public

# 提交並推送
git add .
git commit -m "update"
git push origin main

每次更新博客嗰陣，重複上面幾步就得。

3. 寫個腳本簡化操作

可以將以上步驟寫成一個腳本 deploy.sh：

#!/bin/bash
echo "Building..."
hugo

echo "Deploying..."
cd public
git add .
git commit -m "update $(date '+%Y-%m-%d %H:%M:%S')"
git push origin main
cd ..
echo "Done!"

以後淨係要執行 bash deploy.sh 就完成構建同部署。

呢種方式嘅優點係唔依賴任何第三方 CI 服務，簡單直接；缺點係要手動執行，而且要保證本地 Hugo 環境正常。

方式二：GitHub Actions 自動部署

懶人必備——每次將源碼推上 GitHub，淨低嘅構建同部署全部交畀 Actions 自動搞掂。

1. 創建 Personal Access Token

為咗畀 Actions 可以向頁面倉庫推送代碼，需要一個 Token：

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens(classic)
  2. 生成新 Token，剔選 repo 同 workflow 權限
  3. 複製生成嘅 Token（注意：呢個 Token 只顯示一次，記得保存好）

然後喺源碼倉庫嘅 Settings → Secrets and variables → Actions 度新建一個 Secret，名稱為 TOKEN，填入啱啱複製嘅 Token。

2. 編寫 Workflow 文件

喺源碼倉庫根目錄創建 .github/workflows/hugo.yaml：

name: deploy

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0
              submodules: true       # 如果主題用 git submodule 安裝，需要呢行

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.TOKEN }}
              EXTERNAL_REPOSITORY: <你嘅用戶名>/<你嘅用戶名>.github.io
              PUBLISH_BRANCH: main
              PUBLISH_DIR: ./public
              commit_message: auto deploy

各步驟說明：

步驟 作用
actions/checkout@v4 拉取源碼，submodules: true 同時拉取主題子模組
peaceiris/actions-hugo@v3 安裝 Hugo 環境（extended 版支援 SCSS）
hugo 構建站點，生成 public/ 目錄
peaceiris/actions-gh-pages@v4 將 public/ 推送到頁面倉庫

3. 推送源碼觸發部署 

git add .
git commit -m "new post"
git push origin main

每次 push 到 main 分支之後，GitHub Actions 就會自動執行。可以喺源碼倉庫嘅 Actions 標籤頁度睇構建進度，綠色 ✅ 即係部署成功，之後訪問 https://<你嘅用戶名>.github.io/ 就會見到更新咗嘅博客。

兩種方式對比

手動推送 GitHub Actions
操作 本地行 hugo + 手動 push 只需要 git push 源碼
依賴 本地需要安裝 Hugo 唔需要本地環境
適用場景 臨時更新、唔方便配置 Actions 日常寫博客，自動化最慳心機
複雜度 ⭐ 簡單 ⭐⭐ 需要配置一次 Token 同 yaml

兩種方式唔衝突，可以同時用——配置好 Actions 之後日常自動部署，間唔中需要手動推都完全冇問題。

至此，Hugo 博客嘅搭建、配置同部署就全部完成喇 🎉
