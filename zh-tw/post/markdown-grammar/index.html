標題

標題分為六種標題：

  • 一級標題# 一級：

一級

  • 二級標題# 二級：

二級

  • 三級標題# 三級：

三級

  • 四級標題# 四級：

四級

  • 五級標題# 五級：
五級
  • 六級標題# 六級：
六級

級數越大，標題越小，與HTML中的<h1>一級</h1> <h4>四級</h4>等標題一致。

Markdown HTML 效果
# 一級標題 <h1>一級標題</h1>

一級標題
… … …
###### 六級標題 <h6>六級標題</h6>
六級標題

樣式

Markdown提供了非常多的文字樣式選擇，如加粗，斜體，刪除線等。下面是介紹：

Markdown HTML 效果
*斜體* <em>斜體</em> 斜體
**加粗** <strong>加粗</strong> 加粗
刪除線 <del>刪除線</del> 刪除線

列表

列表語法分為有序列表、無序列表和待辦列表三類。

無序列表

無序列表以-，*，+ 開頭，後面跟一個空格再跟內容，如：

  • 無序列表
    • 無序列表
      • 無序列表
- 無序列表
- * 無序列表
- * + 無序列表

有序列表

有序列表由數字加英文句點加空格再跟內容，如：

  1. 有序列表1
  2. 有序列表2
  3. 有序列表3
1. 有序列表1
2. 有序列表2
3. 有序列表3

前面的數字可以不按順序，如1. 5. 6. 9. ，但是必須從小到大。

待辦列表

待辦列表由-加上空格再加上一對英文方括號[]組成，方括號內需輸入一個空格，如：

- [ ] 待辦1
- [ ] 待辦2
  • 待辦1
  • 待辦2

如果已完成，可以在方括號內輸入X，就像這樣：

- [ ] 已完成待辦
- [X] 未完成待辦
  • 未完成待辦
  • 已完成待辦

表格

在Markdown中，使用管道符|和橫槓-來製作表格。例如：

|表頭1|表頭2|表頭3|
|:--:|:--:|:--:|
|內容1|內容2|內容3|

效果：

表頭1 表頭2 表頭3
內容1 內容2 內容3

中間的|:--:|中的:是用來左對齊或右對齊或者居中的，:在左是左對齊，在右是右對齊，兩邊都有是居中。

註腳

註腳一般用在一些論文或者借鑑，引用了別人文章的地方，比如：

橫眉冷對千夫指，俯首甘為孺子牛。[^1]
[^1]:引用自魯迅《自嘲》

效果：

橫眉冷對千夫指，俯首甘為孺子牛。1

縮寫

縮寫和註腳差不多，不過不需要在文本後面加上[^1]之類的，例如：

Markdown 可以被瀏覽器渲染為HTML。
*[HTML]:HyperText Markup Language（超文本標記語言）

效果：

Markdown 可以被瀏覽器渲染為HTML。

*[HTML]:HyperText Markup Language（超文本標記語言）

公式

公式可以用來寫一些數學方面的公式內容，要以$開頭和結尾，比如：

一元二次方程 $ ax^2 + bx + c = 0 (b^2 - 4ac \ge 0) $ 的解為：
$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$
