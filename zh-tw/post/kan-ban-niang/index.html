再次更新，用上了 Cloudflare 的 R2 儲存桶，綁了kuqilin.eu.org域名，可以 盡情 適度食用了。速度比 jsDelivr 快多了！20 秒之內 99% 的使用者都能加載出來了。都去給我欣賞「泉眼深處」😠😠😠

太好了，經歷各種鬥智鬥勇（bushi）終於把網站看板娘搞好了 —— 一個不會說話的 37。
為什麼說鬥智鬥勇呢？你去看後文。不容易啊，最終發現有這些小白塊大抵是因為大佬解包過程中出了一些小問題，導致模型圖片裡面有一個白塊，當時看模型圖片就感覺奇怪，上 9 看了皮膚，發現本來這裡什麼都沒有，於是用 IsoPix Pro 把白塊擦掉了，發現終於沒有白塊了（應該不會有什麼問題的）。
然後也把模型放置位置和大小做了一些調整。可惜的是暫時還不會怎麼給她新增例如舉牌子、對話方塊之類的，所以看板娘傻傻的。
欸，國內裸連 GitHub 還是不太好，把 moc3 檔案上傳到 jsDelivr 上也沒多快，你們最壞情況要 2 分鐘才能看到美麗的 37！（最好情況是 3 秒）

37 完美的流體

Caution

哈哈哈哈哈，下面的內容沒有時效性了，我搞定了泉眼深處
下文原標題為《網站看板娘 —— 37 完美的流體》

耗費許久，最終 vibe code 了網站的看板娘出來，《重返未來：1999》裡面角色 37 的皮膚——完美的流體。
或許玩過 1999 的人會問：“難道你不覺得快樂的捕鳥人或者泉眼深處更好看嗎？”我會回答：“對！我也想用泉眼深處。”
只不過，這幾個有“億點點”問題： 具體的情況，請看以下圖片： 看到那幾個白塊了嗎？37 的洞二皮也有這個問題，vibe 解決不了 我是廢物 沒辦法了，泉眼深處真的很好看啊，部署出來還會有小鳥在飛來飛去，可是這個白塊真的沒辦法解決，不然也不會用這個 洛天依 完美的流體了。

本來我用的 Reimu 主題是直接能用 Live2d 的，但是沒辦法，你 9 的模型版本太高了，只得自己 vibe 出來 厲不厲害你 Deepseek-V4-Pro 預覽版？

不過還好，這個皮膚也不算難看。並且動作和表情也還是有的。調了一個 5 秒鐘自動切換動畫和一個點選切換動畫。需要注意的是，在顯示寬度小於 960px 的情況下這個看板娘是不會顯示的，就跟側邊欄一樣，她倆是同步的。
壞了，為了加快國內的訪問速度，把這個“可能侵權”的檔案上傳到了圖床，不知道會有什麼風險呢？

還是感覺很可惜，沒能讓泉眼深處當網站看板娘😭😭😭

這些模型都是從https://github.com/myssal/Reverse-1999-CN-Asset/下載的大佬解包資源，如有侵權，請聯絡刪除。
