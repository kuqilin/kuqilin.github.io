棧、佇列和雙端佇列的Python實現

棧、佇列和雙端佇列的Python實現

棧的Python實現

棧是元素的有序集合，新增操作與移除操作都發生在其頂端。棧的操作順序是LIFO(Last In First Out)。 這種東西小學生都會。 如果不會請點選連結檢視。
棧支援以下操作：

  • Stack()建立一個空棧。
  • push(item)講一個元素新增到棧的頂端。需要引數 item ，且無返回值。
  • pop()將棧頂端的元素移除。不需要引數，但會返回頂端的元素，並且修改棧的內容。
  • peek()返回棧頂端的元素，但是並不移除該元素。不需要引數，也不會修改棧的內容。
  • isEmpty()檢查棧是否為空。不需要引數，且返回布林值。
  • size()返回棧中元素的數目。不需要引數，且返回一個整數。
    棧的方法：
棧操作 棧內容 返回值
s.isEmpty() [] True
s.push(4) [4] None
s.push('dog') [4, 'dog'] None
s.peek() [4, 'dog'] 'dog'
s.push(True) [4, 'dog', True] None
s.size() [4, 'dog', True] 3
s.isEmpty() [4, 'dog', True] False
s.pop() [4, 'dog'] True
s.size() [4, 'dog'] 2

程式碼如下： 

class Stack:
    '''這是一個棧'''
    def __init__(self):
        self.items = []
    def isEmpty(self):
        return self.items == []
    def push(self, item):
        self.items.append(item)
    def pop(self):
        return self.items.pop()
    def peek(self):
        return self.items[len(self.items)-1]
    def size(self):
        return len(self.items)
    def __str__(self):
        return str(self.items)
    def __repr__(self):
        return str(self.items)

以上程式碼的棧操作及其返回值： 

>>> s = Stack()
>>> s.isEmpty()
True
>>> s.push(4)
>>> s.push('dog')
>>> s.peek()
'dog'
>>> s.push(True)
>>> s.size()
3
>>> s.isEmpty()
False
>>> s.pop()
True
>>> s.size()
2
>>>print(s)
[4, 'dog']

佇列的Python實現

佇列是有序集合，新增操作發生在“尾部”，移除操作發生在“頭部”。操作順序是FIFO（ First In First Out ） 這東西小學二年級就學了（確信）。 一年級請點選連結學習。
佇列支援以下操作：

  • Queue()建立一個空佇列。
  • enqueue(item)在隊尾新增 item 元素，沒有返回值。
  • dequeue()在隊頭返回並移除一個元素。
  • isEmpty()檢查佇列是否為空，不需要引數，返回布林值。
  • size()返回佇列中元素的數目，整數型。
    佇列的方法：
佇列操作 佇列內容 返回值
q.isEmpty() [] True
q.enqueue(4) [4] None
q.enqueue('dog') ['dog', 4] None
q.enqueue(True) [True, 'dog', 4] None
q.size() [True, 'dog', 4] 3
q.isEmpty() [True, 'dog', 4] False
q.dequeue() [True, 'dog'] 4
q.size() [True, 'dog'] 2

用Python實現佇列: 

class Queue:
    '''這是一個佇列'''
    def __init__(self):
        self.items = []
    def isEmpty(self):
        return self.item == []
    def enqueue(self, item):
        self.items.append(item)
    def dequeue(self):
        self.items.pop(0)
    def size(self):
        return len(self.items)
    def __repr__(self):
        return str(self.items)

以上程式碼的佇列操作及其返回值： 

>>> q = Queue()
>>> q.isEmpty()
True
>>> q.enqueue(4)
>>> q.enqueue('dog')
>>> q.enqueue(True)
>>> q.size()
3
>>> q.isEmpty()
False
>>> q.dequeue()
4
>>> q.size()
2
>>> print(q)
['dog', True]
