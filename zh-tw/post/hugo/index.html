記錄了我在 GitHub Pages 搭建 Hugo 的經歷

Tip

請務必先通讀全文再進行操作，避免一些不必要的錯誤。

安裝 Hugo

Windows

前往官網下載 Hugo 的exe檔案，隨便找個位置放，然後把他新增到環境變數中即可。

Linux

先安裝 Hugo 的二進位制檔案，可以在官網上下載，也可以直接使用軟體包管理器，考慮到apt更新極為緩慢，建議 Debian 系去官網下載deb包進行安裝。

sudo apt install hugo    # Debian 系
yay -S hugo              # Arch 系

安裝完成後，執行hugo version會看到類似如下的提示：

❯ hugo version  
hugo v0.164.0-ce2470e7012b5ab5fc4e10ebe4027e9f8d9e00dc+extended linux/amd64 BuildDate=2026-07-06T16:39:30Z VendorInfo=gohugoio

即安裝完成。

建立專案

我們使用hugo new site <專案名稱>來建立專案，比如：

❯ hugo new site myBlog  
Congratulations! Your new Hugo site was created in /home/kuqilin/myBlog.  
  
Just a few more steps...  
  
1. Change the current directory to /home/kuqilin/myBlog.  
2. Create or install a theme:  
  - Create a new theme with the command "hugo new theme <THEMENAME>"  
  - Install a theme from https://themes.gohugo.io/  
3. Edit hugo.toml, setting the "theme" property to the theme name.  
4. Create new content with the command "hugo new content <SECTIONNAME>/<FILENAME>.<FORMAT>".  
5. Start the embedded web server with the command "hugo server --buildDrafts".  
  
See documentation at https://gohugo.io/.

可以看到成功的提示，接下來cd到專案資料夾myBlog，按照提示進行配置。

建立或安裝主題

顯然，我們是可以自己建立主題的，但是為了白嫖方便，直接前往 Hugo Themes 下載一個稱心的即可，這裡選擇了 hugo-theme-reimu 這個主題。

主題安裝有幾種方式，推薦使用 Git Submodule：

cd myBlog
git init
git submodule add https://github.com/D-Sketon/hugo-theme-reimu.git themes/hugo-theme-reimu

也可以直接下載主題壓縮包，解壓到themes資料夾下。

然後在 hugo.toml 中指定主題：

theme = "hugo-theme-reimu"

配置 hugo-theme-reimu

主題的配置檔案預設在 themes/hugo-theme-reimu/config/_default/ 下。我們不應該直接修改主題檔案，因為更新主題時會將其覆蓋掉，所以應該在專案根目錄的 config/_default/ 下建立同名檔案來覆蓋。我們把params.yml（主題引數）複製即可。

基礎站點配置（hugo.toml） 

baseURL = 'https://<你的使用者名稱>.github.io/'
theme = "hugo-theme-reimu"
title = "xxx's Blog"       # 站點標題
locale = "zh-CN"           # 語言
languageName = "簡體中文"   # 語言名稱
hasCJKLanguage = true      # 是否包含 CJK 字元

[markup.highlight]         # 語法高亮（含程式碼塊必須）
guessSyntax = true
noClasses = false

[markup.goldmark.renderer]
unsafe = true

[markup.goldmark.extensions.passthrough] # 含數學公式必須
enable = true
delimiters.block = [["\\[", "\\]"], ["$$", "$$"]]
delimiters.inline = [["\\(", "\\)"], ["$", "$"]]

unsafe = true 允許在 Markdown 中直接使用 HTML，passthrough 用於支援數學公式的 $...$ 和 $$...$$ 語法。

主題引數配置（params.yml）

在 config/_default/params.yml 中配置主題的各項功能，這裡介紹幾個關鍵項：

導航選單：

menu:
  - name: home
    url: ""
  - name: archives
    url: "archives"
  - name: about
    url: "about"
  - name: friend
    url: "friend"

個人資訊和頭像：

author: <你的名字>
email: <你的郵箱>
avatar: "avatar.jpg"           # 放在 static/avatar/ 下
banner: "images/banner.webp"   # 放在 static/images/ 下

社交連結：

social:
  email: mailto:<你的郵箱>
  github: https://github.com/<你的使用者名稱>
  twitter: https://twitter.com/<你的使用者名稱>

側邊欄和小元件：

sidebar:
  position: left  # 左右可選
widgets:
  - category
  - tag
  - tagcloud
  - recent_posts

評論區（以 Waline 為例）：

comment:
  default: waline
waline:
  enable: true
  serverURL: "<你的 Waline 服務地址>"

啟用功能：

toc: true                # 目錄
dark_mode:
  enable: auto           # 自動跟隨系統
math:
  mathjax:
    enable: true         # 數學公式
show_update_time: true   # 顯示更新時間

更多配置項（滑鼠特效、Live2D、字型、載入動畫等）請參考主題官方文件。

配置完成後，執行 hugo server -D 即可在本地預覽 http://localhost:1313。

其他內容

其他內容，比如更改滑鼠指標、修改字型、文章頭圖、文章封面、網站主題色、短程式碼、友鏈等等，請檢視官方文件，這裡不再贅述。嘻嘻

部署到 GitHub Pages

部署的核心思路是把 Hugo 構建生成的 public/ 目錄推送到 <使用者名稱>.github.io 倉庫。GitHub Pages 會自動將這個倉庫的內容作為靜態網站釋出。

也就是說，我們需要兩個倉庫：

  • 原始碼倉庫（如 hugo-build）：放 Hugo 專案原始檔（Markdown、配置、主題等）
  • 頁面倉庫（<使用者名稱>.github.io）：只放 public/ 裡的靜態檔案

下面分別介紹手動推送和 GitHub Actions 自動推送兩種方式。

方式一：手動推送到 github.io

最直接的方式——在本地執行 hugo 構建，然後把 public/ 目錄的內容推到頁面倉庫。

1. 克隆頁面倉庫 

git clone https://github.com/<你的使用者名稱>/<你的使用者名稱>.github.io.git public

如果 public/ 目錄已存在（Hugo 構建會生成），先刪掉再克隆。

2. 構建並推送 

# 回到原始碼倉庫根目錄，先構建
hugo

# 進入 public 目錄（此時它已經是頁面倉庫的克隆）
cd public

# 提交併推送
git add .
git commit -m "update"
git push origin main

每次更新部落格時，重複上面幾步即可。

3. 寫個指令碼簡化操作

可以把以上步驟寫成一個指令碼 deploy.sh：

#!/bin/bash
echo "Building..."
hugo

echo "Deploying..."
cd public
git add .
git commit -m "update $(date '+%Y-%m-%d %H:%M:%S')"
git push origin main
cd ..
echo "Done!"

以後只需執行 bash deploy.sh 就完成構建和部署了。

這種方式的優點是不依賴任何第三方 CI 服務，簡單直接；缺點是需要手動執行，並且要保證本地 Hugo 環境正常。

方式二：GitHub Actions 自動部署

懶人必備——每次把原始碼推到 GitHub，剩下的構建和部署全交給 Actions 自動完成。

1. 建立 Personal Access Token

為了讓 Actions 能夠向頁面倉庫推送程式碼，需要一個 Token：

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens(classic)
  2. 生成新 Token，勾選 repo 和 workflow 許可權
  3. 複製生成的 Token（注意：此 Token 只顯示一次，務必儲存好）

然後在原始碼倉庫的 Settings → Secrets and variables → Actions 中新建一個 Secret，名稱為 TOKEN，填入剛才複製的 Token。

2. 編寫 Workflow 檔案

在原始碼倉庫根目錄建立 .github/workflows/hugo.yaml：

name: deploy

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0
              submodules: true       # 如果主題用 git submodule 安裝，需要這行

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.TOKEN }}
              EXTERNAL_REPOSITORY: <你的使用者名稱>/<你的使用者名稱>.github.io
              PUBLISH_BRANCH: main
              PUBLISH_DIR: ./public
              commit_message: auto deploy

各步驟說明：

步驟 作用
actions/checkout@v4 拉取原始碼，submodules: true 同時拉取主題子模組
peaceiris/actions-hugo@v3 安裝 Hugo 環境（extended 版支援 SCSS）
hugo 構建站點，生成 public/ 目錄
peaceiris/actions-gh-pages@v4 將 public/ 推送到頁面倉庫

3. 推送原始碼觸發部署 

git add .
git commit -m "new post"
git push origin main

每次 push 到 main 分支後，GitHub Actions 就會自動執行。可以在原始碼倉庫的 Actions 標籤頁檢視構建進度，綠色 ✅ 即為部署成功，隨後訪問 https://<你的使用者名稱>.github.io/ 就能看到更新後的部落格。

兩種方式對比

手動推送 GitHub Actions
操作 本地跑 hugo + 手動 push 只需 git push 原始碼
依賴 本地需安裝 Hugo 無需本地環境
適用場景 臨時更新、不方便配 Actions 日常寫部落格，自動化最省心
複雜度 ⭐ 簡單 ⭐⭐ 需配一次 Token 和 yaml

兩種方式不衝突，可以同時使用——配好 Actions 後日常自動部署，偶爾需要手動推也完全可以。

至此，Hugo 部落格的搭建、配置和部署就全部完成了 🎉
