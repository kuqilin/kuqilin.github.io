高中生申请 JetBrains 学生免费的完整指南：资格条件、三条验证路线（GitHub 学生包 / 官方文件 / ISIC）、申请步骤、续期方法与常见坑。

最近把 CLion 卸载了（它已经吃灰很久），但转念一想：JetBrains 家的 IDE 对在校学生其实一直是正版免费的，高中生在读也算数。这篇把自己整理出来的申请攻略记下来，方便以后续期和分享。

学生免费能拿到什么

JetBrains 对学生有两条免费路线，一条要验证学生身份，一条不用：

1. JetBrains Student Pack（需学生验证）

  • 10 个 IDE 的全功能版：IntelliJ IDEA Ultimate、PyCharm Professional、CLion、GoLand、PhpStorm、WebStorm、DataGrip、Rider、RubyMine、RustRover——即全家桶。
  • JetBrains Academy：IDE 内置的交互式编程课程（Java、Python、Kotlin 等），跟着做题就能学。
  • 求学期间免费，但需要每年续期一次。
  • 毕业后两年内购买任何产品六折。
  • 注意：只能用于学习/个人非商业用途，公司实习、兼职、接外包不能拿它顶。

2. 单工具免费版（无需验证）

只要下载就用，不查身份：

  • IntelliJ IDEA Community、PyCharm Community（社区版，功能已够入门）。
  • CLion、WebStorm、RustRover、Rider、RubyMine、DataGrip 近年开放了非商业免费版（Rider 是 2024 年起免费非商业）。

如果只学一门语言，这档完全够用；想要全家桶完整版，才需要往下走学生验证。

谁有资格

官方要求两条：

  1. 全日制学生，修读学制一年或以上的课程（高中三年制满足；大学、研究生当然也行）。
  2. 验证方式三选一：大学邮箱 / ISIC·ITIC 卡 / GitHub Student Developer Pack。

高中生一般没有大学邮箱，所以实际可行的路线是后两条。另外官方 FAQ 明确说：机构邮箱不被接受仍然可以申请（走官方文件人工审批）。

路线 A：GitHub Student Developer Pack（推荐）

这是高中生最稳的路，因为 GitHub 学生包本身就允许 13 岁以上的中学生申请，而且包里有几十个福利，JetBrains 全家桶只是其中之一。

申请 GitHub 学生包

  1. 注册 GitHub 账号，先把 Profile 里的 Name 改成英文名（和证件拼音一致，如 San Zhang）。
  2. 打开 https://education.github.com/pack/join，点 Student 的 “Get benefits”，登录后填写申请表。
  3. 填表要点（中文高中生专用避坑）：
    • 学校名写英文全称，不要缩写、不要中文；学校官网境外访问不了的就不要填（会直接被拒）。
    • 学校类型选 High School。
    • 有学校邮箱（edu.cn 等）优先填，通过率最高；没有就跳过。
    • 申请过程不要挂 VPN（IP 与学校所在国家不符容易被标记）。
  4. 上传证明：学生证、在读证明、成绩单等，必须英文（自己翻译的不认，最好学校出具）；照片要清晰、包含学校名/姓名/有效期。没有 edu 邮箱时只能用摄像头实时拍摄，不能直接传文件。
  5. 提交后等 3～15 个工作日，结果发邮件。
  6. 被拒了别慌：常见原因是学校官网境外不可访问、材料不够清晰。去 GitHub Support 开工单申诉，附上更充分的材料（社区经验里 ISIC 学生证 + 工单几乎必过）。

用 GitHub 包换 JetBrains

GitHub 学生包通过后，在 https://education.github.com/pack 里找到 JetBrains 卡片，点进去按提示用 GitHub 账号授权，会跳转到 JetBrains 完成教育授权绑定，之后你的 JetBrains Account 里就会出现全家桶授权。

路线 B：JetBrains 官网官方文件（人工审批）

不想折腾 GitHub 的，直接走 JetBrains 官方文件路线：

  1. 先自测资格和申请方式：https://www.jetbrains.com.cn/lp/edu-program-user-flow/（回答"是→否"的组合题，会引导到对应的申请方式）。
  2. 新申请入口：https://www.jetbrains.com/shop/eform/students，申请方式一行选「官方文件」。
  3. 上传材料：
    • 大陆高校在校生：必须上传学信网学籍验证报告 PDF（先在学信网确认报告已开启且在有效期内，PDF 要带有效验证码）；学生证、在读证明、成绩单可作辅助材料。
    • 高中生没有学信网，用学生证 / 学校开具的在读证明（中英对照更稳）。
  4. 官方文件是人工审批，提交后 1～2 周邮件通知结果（不会立即收到授权邮件）。
  5. 通过后收 “JetBrains Educational Pack Confirmation” 邮件，点邮件里的链接绑定你的 JetBrains Account 即完成。

路线 C：ISIC 国际学生证

ISIC 是付费的国际学生证（约几十到一百元），JetBrains 支持用它验证。单独为 JetBrains 办一张性价比不高，但如果学校本来组织办理，或你已经有了，这是最快的验证方式（系统核实后基本立即通过）。

拿到授权之后

  1. 申请通过 → 邮件链接绑定 JetBrains Account（没有就注册一个，建议用申请时填的邮箱，入口 https://account.jetbrains.com.cn）。
  2. 登录 JetBrains Account 确认授权状态；若授权下方出现蓝色 “Please review License Agreement”，点它同意授权条款，否则无法使用。
  3. 装 JetBrains Toolbox（https://www.jetbrains.com/toolbox-app/），想装哪个 IDE 点哪个，登录 JetBrains Account 联网激活即可。

续期（每年一次）

授权有效期一年，快到期时：

  1. 登录 https://account.jetbrains.com.cn，找到对应授权，点 “Renew my Education Pack” 链接开启续期申请表。
  2. 按当年提示重新验证学生身份（仍在读即可继续白嫖）。
  3. 别走错入口：续期不是重新填新申请表，新申请入口只给从未成功申请过的人用。

大陆用户的几个坑

  • JetBrains AI 已于 2024 年 7 月停止中国大陆服务，IDE 里的 AI 补全/聊天用不了（2025 年起官方也在收缩中国区销售），但学生授权本身不受影响。
  • 教育授权不能商用：实习、兼职、外包都得买商业版，别混用。
  • GitHub 审核期间不要挂代理；JetBrains 官方文件审批期间留意垃圾邮件箱。
  • 每年毕业季前后是审核高峰，最好提前一个月续期，避免断档。
